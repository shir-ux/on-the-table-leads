# On The Table - דף ניהול לידים לאורטל

> הוקם 15.9.2026. ממשק נוח מעל גיליון הלידים - אורטל עובדת מהדף (בעיקר מהנייד), והשיטס מתעדכן בלייב.
> משלים את `../leads-crm-spec.md` (מבנה הגיליון, סטטוסים, אוטומציות).

## ארכיטקטורה - למה ככה

- **דף סטטי ב-GitHub Pages** (כמו ספריית הפרומפטים) - לאורטל אין חשבון Claude, ולכן Artifact עם מסד נתונים לא רלוונטי (פתוח רק לחברי הארגון של שיר). הוחלט 15.9.2026.
- **Google Apps Script כ-Web app** בתוך פרויקט הסקריפטים של השיטס עצמו - הדף קורא וכותב דרכו ישירות לגיליון. השיטס נשאר מקור האמת היחיד; אוטומציית Make ממשיכה להזרים לידים אליו כרגיל.
- **קוד כניסה (PIN)** נבדק בצד של גוגל, לא בדף - הדף ציבורי אבל בלי הקוד אי אפשר לקרוא או לכתוב כלום.
- רשימות הסטטוסים והסיבות נקראות בלייב מהתפריט הנפתח עצמו (אימות הנתונים על עמודות G ו-H). עמודות N/O הן גיבוי בלבד. סטטוס חדש בשיטס מופיע בדף בלי לגעת בקוד (עודכן 4.10.2026).
- צבעי הסטטוסים מוגדרים בדף (`STATUS_COLORS` ב-`index.html`) - גוגל לא חושף לקוד את צבעי התפריט הנפתח. מקור אחד לכפתורים ולתוויות.
- קישור אישי לליד: `#lead=<מספר שורה>` פותח את חלון העדכון של הליד. מספר שורה ולא טלפון, כדי שפרטים אישיים לא יופיעו בקישור.
- "לא רלוונטי" מחייב סיבה + דיווח. "חיוג" מסמן "נוצר קשר ראשוני" לליד חדש בלבד.
- עיצוב: שפת SDM הכהה (סגול-זהב), כמו הדוח החודשי. `logo.png` הוא עותק מ-`skills/sdm-brand-doc/assets/`.
- **עמודות לפי שם כותרת** (5.10.2026): הסקריפט מוצא כל עמודה לפי הכותרת שלה (`HEADERS` ב-`apps-script.gs`), לא לפי מיקום. חובה: שם מלא, טלפון, סטטוס. עמודה שלא קיימת בגיליון פשוט לא נקראת ולא נכתבת. זה מה שמאפשר לשכפל ללקוח עם סדר עמודות אחר.
- **לשוניות שהסקריפט יוצר לבד**: "משימות" (שורה למשימה) ו"היסטוריה" (שורה לכל שינוי שנעשה דרך הדף; מקושר לליד לפי 9 הספרות האחרונות של הטלפון).
- **עמוד ליד**: לחיצה על שם הליד. פרטים, תיעוד, תגובות, היסטוריה. ההיסטוריה נטענת רק בפתיחת ליד.
- הדף שולח לשיטס רק שדות ששונו בפועל, כדי לא לדרוס תאים שהוא לא יודע לקרוא.
- עדכון שורה מאומת מול שם+טלפון לפני כתיבה - הגנה מפני מיון/מחיקה בשיטס בין רענון לשמירה.

## קבצים

- `index.html` - הדף (עברית RTL, מיתוג SDM, מובייל-first). לשוניות: לידים / פולואפ להיום / סיכום. כולל הוספת ליד ידנית, חיוג ווואטסאפ בלחיצה.
- `apps-script.gs` - הקוד שיושב ב-Apps Script של השיטס (קובץ נפרד לצד otb-onedit הקיים).

## התקנה - צעדים של שיר (חד-פעמי)

1. לפתוח את השיטס ← Extensions ← Apps Script ← קובץ חדש בשם `lead-api` ← להדביק את תוכן `apps-script.gs`
2. לשנות בראש הקובץ את `PIN = 'CHANGE_ME'` לקוד שסוכם עם אורטל
3. Deploy ← New deployment ← Web app ← Execute as: **Me** ← Who has access: **Anyone** ← Deploy
4. להעתיק את כתובת ה-Web app (מסתיימת ב-`/exec`) ולהדביק ב-`index.html` במקום `PASTE_WEB_APP_URL_HERE`
5. להעלות את `index.html` לריפו GitHub עם Pages ולשלוח לאורטל את הלינק + הקוד

עדכון עתידי של הסקריפט: לערוך את הקוד ← Deploy ← Manage deployments ← עיפרון ← Version: New ← Deploy (הכתובת נשארת אותה כתובת).
